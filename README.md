Épicas

1. Catálogo de productos
Gestión y visualización de gorras: categorías, variantes (talla, color, marca), imágenes, precios, stock disponible.

2. Registro y gestión de usuarios
Creación de cuentas, login, perfil de cliente, recuperación de contraseña, direcciones guardadas.

3. Carrito de compras
Agregar/quitar productos, modificar cantidades, guardar carrito, cálculo de subtotales.

4. Proceso de pago (Checkout)
Selección de método de pago, integración con pasarelas (PayPal, tarjeta, PSE si es en Colombia), confirmación de orden.

5. Gestión de pedidos
Seguimiento del estado del pedido (pendiente, en proceso, enviado, entregado), historial de compras del cliente.
