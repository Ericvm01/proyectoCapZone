# 🛒 Proyecto CapZone - Sprint 1: Catálogo de Productos

> Sistema de gestión y visualización de productos para la plataforma CapZone.

## 📋 Descripción del Proyecto
CapZone es una aplicación diseñada para gestionar y comercializar productos de manera eficiente. Este repositorio contiene la documentación, arquitectura y código fuente del proyecto. En este **Sprint 1**, nos hemos enfocado en el desarrollo, definición de características y requerimientos de la funcionalidad del **Catálogo de Productos**.

---

## 🚀 Objetivos del Sprint 1
- Definir los requerimientos funcionales y no funcionales del catálogo de productos.
- Estructurar la arquitectura base del módulo de catálogo.
- Diseñar la interfaz y flujo de usuario para la visualización de productos.
